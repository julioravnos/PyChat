Python Client/Server LAN Chat

Este script simples foi desenvolvido para uma simples comunicação de rede, oferecendo conexão simples e direta entre o servidor e o cliente.
Para uso, ajuste o endereço de IP no servidor e no cliente nos locais indicados dentro do script.

Comandos adicionados no script:

/quit - encerra o chat
/help - mostra ajuda
/dm <nickname> <mensagem> - Envia chat privado para o usuário
/list - Mostra os usuários e canais criados
/join <#sala> - Entra em um canal (ex: /join #dev).

Este é um script simples e sem recursos de proteção não devendo ser usado em ambiente de produção sem criar respectivas proteções.
